# NAF Flow

Native JavaScript components, reactive state and backend HTML updates for server-rendered
NAF views. The optional plugin integrates automatically with `naf/view`.

## Documentation

[Flow guide](https://nafphp.github.io/docs/flow/) in the
[NAF documentation repository](https://github.com/nafphp/docs).

## Install

Requirements and installation steps are in the
[installation guide](https://nafphp.github.io/docs/flow/#installation).
